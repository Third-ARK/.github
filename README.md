# .github

This repository holds the organisation profile only. The one file that matters
is `profile/README.md`, which GitHub draws on the
[Third-ARK organisation page](https://github.com/Third-ARK).

**This repository is public, and it is the only public one.** GitHub only draws
that file while it is, which is why it is. Everything in it is the five links
on the profile and nothing else.

**Download ARK O/S points at the site, not at a repository.** The releases
repository is private until the first release is published, and a link into a
private repository answers 404 to everyone outside the organisation, so until
launch the download link goes to www.third-ark.com/get. It is on the
launch-day list to point back at the releases page on the day that page is
public.
